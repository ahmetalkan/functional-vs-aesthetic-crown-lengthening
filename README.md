# Functional vs aesthetic crown lengthening: a consult brief

A consult brief that separates functional from aesthetic crown lengthening, citing AAP, ADA and NIDCR.

This is a free, standalone mini-resource. The live HTML page is intended to be served from:

- Render: `https://functional-vs-aesthetic-crown-lengthening.onrender.com/`
- GitHub Pages: `https://ahmetalkan.github.io/functional-vs-aesthetic-crown-lengthening/`

It cites public pages on [crownlengtheningcost.com](https://crownlengtheningcost.com/) and official reference sources listed at the bottom of the page. Nothing here is a substitute for advice from a qualified professional.
